# Contributing

As a general rule, use of AI is heavily discouraged. In particular, issues and pull requests with an obviously AI-generated description may be closed without warning.

1. Make sure to write all descriptions and documentation yourself. Don't copy an agent's output into the message box, and don't delegate the creation of issues to an agent.
2. When contributing code, there is no certain way to determine if AI was used or not. If you use AI, make sure to verify all output manually, and try not to write more than is strictly necessary.
3. Don't pass feedback on a Pull Request directly to an agent, but try to understand and fix it yourself.
4. If you aren't a native English speaker, using translation software is okay!
